# CTAF Stage 12 — Within-Machine Pseudo-Anomaly Representation Learning Preregistration

## 1. Motivation

CTAF V39–V57 has systematically eliminated all unsupervised and proxy-supervised training objectives that do not target within-machine anomaly detection:

| Stage | Hypothesis | Best Result | Verdict |
|-------|-----------|-------------|---------|
| V37 | AE reconstruction + teacher-student | hmean 0.563 | plateaued (best objective, but low-FPR tail not solved) |
| V48–V49 | hard-normal consistency | q99 down, no hmean gain | mechanism positive, method negative |
| V52–V53 | non-contrastive invariance SSL (VICReg) | 7/7 gates fail | collapses normal/anomaly distinction |
| V54–V56A | external frozen BEATs | hmean 0.579 but pAUC/q99 fail | machine-level complement not sample-level distillable |
| V57 | AAM-softmax machine-type proxy | accuracy 0.9999, compactness 0/7 | **machine-type separability already maxed out** |

**V57 is the most instructive negative in the entire CTAF series.** It proves that V37's frozen latent_summary already has near-perfect machine-type classification (linear accuracy 0.9999, confusion matrix near diagonal). Each machine's normal samples form an extraordinarily tight cluster (cosine spread 0.002–0.053). The bottleneck is not between-machine separability—it is **within-machine** discrimination between normal and near-normal anomalous samples.

Therefore Stage 12 does **not** continue:

- machine-type classification or any proxy-label discrimination
- BEATs distillation or external frozen representations
- VICReg or any invariance SSL
- hard-normal consistency or tail-compression losses
- scoring-rule replacement on frozen features
- frontend or pooling replacement

---

## 2. Hypothesis

**Core hypothesis:**

> CTAF full_5view contains local TF structure cues useful for anomaly detection, but AE/TS/VICReg/AAM training objectives do not explicitly enforce sensitivity to local structural violations within the same machine type. A normal-only binary pseudo-anomaly discrimination objective—where the encoder must distinguish clean normal samples from same-machine local TF patch replacements—can learn latent_summary features that respond to within-machine structural corruption while preserving the full_5view frontend and kNN inference protocol.

Design rationale:

The encoder is presented with clean normal samples and their pseudo-anomalous variants. The pseudo-anomalies are generated by replacing a local TF patch in a normal sample with the corresponding patch from another normal sample of the **same machine type**. This preserves machine-type identity (V57-proven already separable) while creating a local "foreign" insertion that mimics the type of structural violation an anomaly might contain. The binary classifier head trains the encoder to respond to this violation. At inference, the classifier is discarded—the encoder's latent_summary is expected to naturally push real anomalies away from the normal cluster because anomalies contain local structural violations similar to the pseudo-anomalies the encoder learned to detect.

This hypothesis fundamentally reverses the logic of all previous CTAF experiments: instead of asking "how do we tighten the normal boundary?", it asks **"can we teach the encoder what a within-machine structural violation looks like, using only normal samples?"**

---

## 3. Primary Candidate

**One candidate only:** `full_5view + same-machine local TF patch replacement + binary pseudo-anomaly discrimination`

Fixed rules:

- Input: full_5view tensor [B, 5, F, T]
- Clean sample: original train-normal
- Pseudo-anomaly: same-machine local TF patch replacement
- Patch donor must come from the same machine type (different sample)
- No real anomaly labels in training
- No test data in training
- No BEATs or external representations
- No score fusion
- No per-machine patch size or replacement rule

---

## 4. Pseudo-Anomaly Generation

### Fixed Design Draft

For each clean normal sample in a batch:

1. Select a random donor sample from the same machine type
2. Select a rectangular TF region from the donor at a random position
3. Replace the corresponding region in the clean sample with the donor patch
4. Label: clean = 0, pseudo-anomaly = 1

### Geometry Constraints

- Patch donor is always from train-normal (same split, same machine)
- Donor cannot be the same sample as the clean anchor
- Patch covers a small fraction of the total time and frequency axes

### Explicitly Prohibited

- No per-machine patch size
- No patch size sweep
- No multiple pseudo-anomaly types (e.g., noise injection, frequency shift) in Stage 12 first version
- No real anomaly data as pseudo-anomaly donor
- No test normal data in patch generation

## 5. Training Objective Draft

| Component | Specification |
|-----------|---------------|
| Encoder | viewwise_unshared_late_fusion (lc=64, sc=8, pvc=16, dp=0.0) |
| Frontend | full_5view only |
| Representation | global latent_summary (channel-wise mean + std + max, 192-dim) |
| Classification head | MLP binary classifier (192 → 64 → 1), ReLU, no dropout |
| Loss | binary cross-entropy (BCE) |
| Training data | source train-normal only (used both as clean anchors and patch donors) |
| Anomaly labels | not used |
| Batch composition | 50% clean, 50% pseudo-anomaly (random pairing within batch) |

### Inference

- **Classifier head is discarded**
- Scoring: latent_summary_knn (k=5) on source train-normal memory
- No score fusion, no per-machine selection

### Possible Extension: Pure BCE vs BCE + Reconstruction

Whether to combine BCE with an auxiliary reconstruction loss (preventing catastrophic forgetting of basic acoustic structure) or use pure BCE is a decision for the human review phase. Pure BCE is the simpler and more principled choice for testing the hypothesis; reconstruction auxiliary may stabilize training but risks diluting the anomaly-sensitivity signal.

---

## 6. Difference from Previous Stages

### vs V37 Teacher-Student

V37 learns to predict the teacher's local latent features—an unsupervised signal with no anomaly semantics. Stage 12 learns to detect within-machine structural corruption explicitly, using only normal samples to construct the training signal.

### vs V53 VICReg SSL

VICReg learns augmentation invariance—it smooths out differences between two augmented views, potentially erasing the very local structure this hypothesis targets. Stage 12 explicitly highlights and penalizes local structure change.

### vs V57 AAM-Softmax Proxy Classification

AAM learns between-machine separation (gearbox vs fan). V57 proved this separation is already perfect and has no tightening room. Stage 12 learns within-machine structure sensitivity (clean gearbox vs gearbox with a local foreign patch).

### vs V54–V55 BEATs

BEATs introduced external frozen representations. Stage 12 does not use external models, does not replicate a published method, and preserves CTAF's own full_5view frontend throughout.

---

## 7. Risk

This approach carries specific risks that must be explicitly registered:

1. **Pseudo-anomaly is an artificial construct.** The TF patch replacement operation may create artifacts (sharp patch boundaries, unnatural transitions) that are trivially detectable and do not generalize to real acoustic anomalies.

2. **The encoder may learn to detect the patch boundary rather than the structural violation.** If the task is too easy (perfect patch detection accuracy), the learned features may be useless for real anomaly detection.

3. **Patch replacement may damage the normal semantic structure too aggressively.** If the operation creates something too dissimilar from any real acoustic signal, the representation may not transfer to real test data.

4. **Normal q99 inflation is a known failure mode.** If pseudo-anomaly training causes the encoder to assign higher scores to normal samples as well, the familiar normal-tail inflation pattern will appear.

5. **The machine-specific tradeoff pattern may recur.** If pseudo-anomaly training helps toytrain/valve but degrades bearing/fan, this would be the same pattern that has ended every previous CTAF stage since V39.

## 9. Failure Criteria

Stage 12 first implementation is recorded as negative if:

- hmean is clearly below V37 baseline
- pAUC is below V37 baseline
- normal q99 increases
- bearing / fan / valve collapse
- toycar degrades
- only one machine improves
- pseudo-anomaly binary classification accuracy is near-perfect but ASD metrics degrade (trivial task)
- useful results require patch size sweep
- useful results require score fusion

## 12. Final Sentence

Stage 12 is a new within-machine anomaly-sensitive representation hypothesis. It must not be treated as a continuation of machine-type proxy classification, BEATs adaptation, or scoring-rule search. No implementation or training is authorized until this preregistration is reviewed and approved.
